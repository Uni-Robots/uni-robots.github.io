# Uni-Robots

Site institucional da equipe UniRobot.

## Estrutura
- `index.html` — Início (hero)
- `sobre.html`, `projetos.html`, `equipe.html`, `patrocinadores.html`, `redes.html`, `contato.html`
- `css/` — estilos | `js/main.js` — dados da equipe/projetos e interações
- `assets/images/team/` — fotos dos membros (nomes sem acento/espaco)

## Como editar a equipe
Edite o array `teamMembers` em `js/main.js` e coloque a foto (800x800 .webp) em `assets/images/team/`.
